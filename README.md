# reiko
Today I am giving you access to install a toplist of over 120 hitting linux software packages to your machine.
## Setup guide
Download reiko and reiko48.png from the releases page.
Then create a new text document, paste the code, correct the paths, save and launch it as trusted.
```
[Desktop Entry]
Name=reiko package manager
Exec=/home/username/.local/reiko
Icon=/home/username/.local/reiko48.png
Description=Please specify the paths manually. 
Type=Application
Categories=Utility
Terminal=true
```
